# Product Requirements Document (PRD)
## Overview
An automated counting system capable of identifying and tallying all types of goods—including boxes, cement sacks, and iron rods. The system automatically captures Product IDs, item names, and categories with precise counts.

## Features
- Real-Time CV & Biometric Detection for Live Preview
- Face recognition integration for carriers
- Inventory counting logic for boxes and singles
- Live snapshot capturing and event storage
- Unified MJPEG streaming
